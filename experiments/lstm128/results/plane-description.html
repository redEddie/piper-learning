목적

Piper가 빈손에서 물체를 집어 그릇에 놓는 작업에서, 작은 LSTM이 MLP보다 유리한지 실제 강화학습으로 비교한다. SHOW-68 Mamba2 후속 실험의 기준 모델을 확보한다.

이 이슈에서 다루는 범위

1층·폭128 LSTM 구현 → CPU 테스트 → MLP/LSTM 각각 1,677만 step 학습 → 같은 초기 장면에서 성공률 평가 → 학습 속도·실제 동작 이미지 저장까지 완료했다. 아래는 scripted grasp가 아닌 학습된 정책의 결과다.

실제 수행 범위에서 빠진 부분

학습 random seed는 모델별 7 한 개다. 여러 seed로 독립 반복 학습하지 않았다. Domain randomization은 두 모델 모두 켰으며 반복 학습 검증과는 별개다. 실제 로봇 배포·가림 시험·Mamba2 학습·동일 파라미터 수 비교·정확한 training resume은 수행하지 않았다. 원 논문 폭1024와 달리 폭128로 축소한 모델이다.

이 비교에서 LSTM의 DR 성공률 차이는 +10.2%p, 학습 처리량은 MLP의 91.0%였다. 학습 seed 한 개의 결과이므로 일반적인 우열을 입증하지 않는다.

기존 MLP와 구별: 앞선 stock Brax 학습의 같은 1,677만-step 체크포인트는 DR 86.2%, DR 끔 91.4%였다(그래프 점선). 기존 파일은 읽기만 했다. 기존 학습기는 SGD 전에, 이번 실험은 수집·SGD 중 고정한 뒤 관측 정규화를 갱신한다. 이 차이를 통제하려고 같은 실험 학습기에서 MLP를 새로 학습한 것을 주 비교군으로 삼았다. 기존 MLP 성능이 표의 새 비교군 수치로 바뀐 것은 아니다.

실제 동작 사진과 학습 곡선

실제 저장 trajectory를 렌더링했다. actor마다 episode 하나를 선택한 예시이며 전체 성능은 위 표로 판단한다. 최종 성공 여부와 시각을 이미지에 표시했다.

아래 보상 곡선은 여러 단계에서 시작하는 학습 분포의 지표이며, 빈손 성공률을 뜻하지 않는다.

구현·비교 조건

LSTM actor는 기억층1개(hidden/cell128) → 출력 LayerNorm → MLP [256,256]이다. critic은 두 모델 모두 같은 memoryless MLP [256,256]이며 actor에 privileged state를 넣지 않았다. 환경마다 기억을 분리하고 종료된 환경만 초기화한다. 현재 가중치로 episode의 과거 관측을 재처리(burn-in)한 뒤 16-step sequence를 학습한다. PPO loss·GAE·행동 분포는 Brax 구현을 재사용했다.

공통: RTX3090, MJX-Warp, 1024 환경, 학습16,777,216 step, episode80 step, rollout16 step, minibatch256 sequence ×4, epoch4, learning rate0.0003. 보상·관측·랜덤화 설정은 같다. actor 크기와 초기 파라미터는 다르다. step/s는 모든 환경의 제어 transition을 합친 수집+PPO 업데이트 속도이며 실로봇 Hz가 아니다. 첫 컴파일 iteration을 제외하고 JAX 완료를 기다려 측정했다. 정책에 따른 접촉 궤적 차이와 기억 재처리 비용도 포함한다.

검증·기존 작업 보호

CPU 테스트7개, 실제 CPU PPO64 transition, 두 모델의 GPU 학습과 체크포인트 평가를 통과했다. sequence/step 결과 일치·환경별 기억 초기화·시간 gradient·prefix 재처리·critic 입력 분리·저장/복원을 확인했다. 각 조건의 물리 실패와 신뢰구간은 첨부 JSON에 있다. Wilson 신뢰구간은 평가 episode 오차만 나타내며 학습 seed 간 변동성은 아니다.

기존 학습과 후속 평가가 스스로 끝난 뒤 GPU가 1분간 비어 있는지 확인하고 새 작업을 순차 실행했다. 기존 프로세스·파일을 수정하지 않았다. 외부 GPU 작업이 나타나면 학습 반복 사이에 양보하도록 구성했으며, 10초 간격 점유 표본의 외부 겹침은 0건이었다. 이미지·JSON 첨부4개는 다시 내려받아 SHA-256 일치를 확인했다.
