실제 수행 범위에서 빠진 부분

모델별 학습 seed는 7 한 개다. 여러 학습 random seed를 사용한 독립 반복 학습은 수행하지 않았다. Domain randomization은 두 모델 모두 켰으며 반복 학습 검증과는 별개이다. 실제 로봇 배포·가림 스트레스 시험·Mamba2 학습·동일 파라미터 수로 맞춘 실험·시뮬레이터 상태까지 복원하는 정확한 training resume은 수행하지 않았다. 원 논문의 폭1024 LSTM과 동일한 모델 크기의 재현은 아니다.

기존 Brax MLP 결과와 구별

앞선 백그라운드 학습의 16,777,216-step 체크포인트는 같은 평가 환경·동일한 task 소스에서 DR 86.2%, DR 끔 91.4%였다. 기존 파일은 읽기만 했으며 수정·재학습하지 않았다. 그래프 점선이 이 보조 기준이다.

기존 stock Brax adapter는 SGD 전에 관측 정규화를 갱신한다. 이 실험 adapter는 수집과 SGD 동안 정규화를 고정하고 SGD 뒤에 갱신하며, sequence와 현재 가중치로 계산한 기억을 사용한다. 따라서 새 MLP를 같은 adapter에서 다시 학습한 결과를 주 비교군으로 두고 기존 MLP 결과는 별도로 표시했다. 두 결과를 같은 실행 결과로 취급하거나 기존 MLP가 새 MLP 수치로 바뀌었다고 해석하면 안 된다.

LSTM이 기억하는 방식

실기에서 얻을 수 있는 현재 actor 관측(이전 행동 포함) → 1층 LSTM(hidden/cell 각각128) → 출력 LayerNorm → swish MLP [256,256] → tanh-normal 연속 행동 분포. Critic은 privileged observation을 받는 memoryless MLP [256,256]이며 두 모델 모두 82,945 parameters이다. actor에 참 물체 상태나 미래 관측을 추가하지 않았다.

환경마다 cell/hidden 상태를 분리하고 종료된 slot만 초기화한다. rollout 경계에서와 각 SGD 미니배치에서 현재 가중치로 해당 episode의 실제 과거 관측을 재처리한다(burn-in). prefix gradient는 끊고 16-step sequence에 truncated BPTT를 적용한다. 시간 step을 무작위로 섞지 않고 sequence 단위로 미니배치를 구성한다. PPO loss·GAE·행동 분포는 기존 Brax 구현을 재사용한다.

비교 조건과 속도 해석

RTX3090 한 장, MJX-Warp, 병렬1024 환경, 제어0.1초·물리0.005초, episode80 step, rollout16 step, 미니배치256 sequence ×4, epoch4, learning rate0.0003, discount0.99, GAE0.95, PPO clip0.2, entropy0.001, global gradient clip1.0. stage 입력 없음, 크기 관측 있음, bowl-arm collision 있음. 두 모델 모두 관측 잡음·지연·물리 domain randomization을 켜고 처음부터 학습했다.

표의 step/s는 모든 병렬 환경의 제어 transition 수를 합산한 수집+PPO 업데이트 처리량이며 실로봇 제어 Hz가 아니다. JAX 완료를 기다려 시간을 쟀고 최초 iteration은 steady-state 계산에서 제외했다. 두 모델이 만드는 접촉 궤적 차이와 recurrent prefix 재처리 비용도 포함하므로 순수 신경망 kernel benchmark는 아니다.

  • MLP: loop wall time 11.82분, 첫 iteration(컴파일 포함) 21.03초, 이후 수집 649.05초 + PPO update 12.07초. 프로세스 전체 실행 13.20분.
  • LSTM: loop wall time 12.92분, 첫 iteration(컴파일 포함) 22.81초, 이후 수집 646.05초 + PPO update 80.16초. 프로세스 전체 실행 13.36분.

MLP 다음 LSTM 순으로 실행했으므로 startup cache 상태가 다르다. 프로세스 전체 시간에는 import·초기 환경 준비·컴파일·로그·체크포인트 저장이 포함된다. 전체 startup 시간을 architecture 자체의 속도 차이로 해석하지 않는다.

검증 및 통계적 한계

CPU 테스트 7개 통과: sequence/step 일치, slot별 reset, 현재 가중치 prefix replay, 시간 gradient와 reset 경계, privileged 입력 분리, 체크포인트 round-trip, 동적 burn-in 이후 SGD gradient. CPU 실제 PPO64 transition/4 update도 통과했다. GPU에서도 두 정책의 파라미터 변경과 유한 loss/gradient를 확인했고 시작·비어 있지 않은 prefix·여러 update 후 행동 log-prob를 대조했다.

  • MLP / dr: 74.0–82.2% (최종 성공률 95% Wilson interval), ever 성공률 79.4%, 물리 실패 0건
  • MLP / nodr: 82.7–89.5% (최종 성공률 95% Wilson interval), ever 성공률 87.0%, 물리 실패 0건
  • LSTM / dr: 85.0–91.4% (최종 성공률 95% Wilson interval), ever 성공률 89.3%, 물리 실패 0건
  • LSTM / nodr: 86.4–92.5% (최종 성공률 95% Wilson interval), ever 성공률 90.1%, 물리 실패 0건

위 신뢰구간은 고정된 학습 정책에 대한 episode-level Wilson interval이며 학습 random seed 간 변동성을 나타내지 않는다.
