# SHOW-103: QP v1 / a5 / jerk100 재학습

| 관절 참조 제한 | 이전 | 이번 |
|---|---:|---:|
| 속도 | 0.75rad/s | 1.0rad/s |
| 가속도 | 4rad/s² | 5rad/s² |
| jerk | 300rad/s³ | 100rad/s³ |

5rad/s²는 단위상 가속도다. 이번 시뮬레이션에서 채택한 설정값이며 펌웨어를 조회하거나 실제 로봇을 구동하지 않았다. 기존 실험 설정과 체크포인트는 보존한다.

## 학습에 적용한 비용

운반 시작 후 유효한 첫 해제 전까지 매 정책 스텝(100ms)에:

`C = 0.6 + 0.8 × (max(dxy−17mm,0)/50mm)² + 0.8 × ez/(40mm+ez)`

- `dxy`: 큐브 중심과 그릇 중심 사이의 수평 거리.
- `ez`: TCP가 그릇 내부 바닥 기준 50~60mm 높이 구간에서 벗어난 거리.
- 잘못 해제하면 첫 접촉 상실 시의 오차를 고정한다. 빈손 이동·재파지로 비용을 지울 수 없다.
- 충격·해제 후 로봇 재접촉, 액션 크기·변화 비용도 기존 값을 유지한다.
- 과제 실패(12초 이내 최초 파지 실패 / 운반 후 그릇 밖 탁자 착지)에는 현재 비용과 남은 할인 비용을 정산하고 즉시 초기화한다.
- 제어기 보호 중단은 별도 항목이며 과제 실패 정산 대상에 포함하지 않는다.

## 학습·평가

- 1024환경, 처음부터 50,331,648전이, seed7. 정책·가치함수·정규화 통계 모두 새로 초기화한다.
- 초기화 40/20/20/20 유지. 마지막20% 중 가까운 놓기는 전체5%다.
- 보상 구조·형상·개폐 순서 유지. 액션 배율은 선속도0.05m/s, 각속도0.5rad/s를 유지한다.
- 약839만 전이 간격으로 PPO 기본 평가·체크포인트 저장. 전체 학습 후 초기화별 각384회(128환경×3seed) 외부 평가.
- 초기화별 **전체 과제 완료율**과 **정상 높이 해제→착지→재접촉 없는 철수 완료율**을 구분한다. 파지 시간 초과·그릇 밖 낙하·제어기 중단도 별도 집계한다.
- 조기 실패 이후 새 에피소드에서 얻은 성공은 이전 시도의 성공률에 합산하지 않는다. 종료 전 물리 상태를 metric에 보존하여 첫 에피소드만 평가한다.
- 종료 후 현재 실행의 마지막 두 체크포인트만 남기고 앞선 중간 체크포인트를 정리한다. 다른 실험은 삭제하지 않는다.
- 진행 상태: `status.json`. 학습 원본 로그: `runs/show103/logs/qp-v1-a5-j100-training.log`. 완료 후 평가: `evaluation.json`.
