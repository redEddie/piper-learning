실행 완료: 학습 약49분15초, 네 체크포인트 평가 총6,144회에서 네 초기화 모두 전체 완료0%였다.
50% 승급 기준을 충족하지 못했다. [최종8배 초기화별 진단 영상·보상 동작 확인](diagnosis-8u.md)을 참고한다.

2026-10-30 사용자 지시에 따라 8,388,608전이를 단위로 새 MLP를 처음부터 학습한다.
4,096환경, seed7, 고정 기하·네 초기화40/20/20/20%, 동역학 DR와 기존 보상·제어 제한을 유지한다.
원본 정책과 검증용131,072전이 모델은 보존한다. 이번 실행은 warm-start를 사용하지 않는다.

## 실행

```bash
export PYTHONPATH="$PWD/src:$PWD/runtime/src"
scripts/run.sh .venv/bin/python -u scripts/show103/run_stage_campaign.py \
  --config configs/show103/stage-reward-v1-4096-2-4-6-8.yaml \
  --output runs/show103-fixed-4096-s7-2-4-6-8u-20261030
```

한 번의 학습이 끝난 뒤 2/4/6/8배 체크포인트를 순서대로 평가한다.
각각 빈손A / 열린 파지 직전 / 들고 있음 / 그릇 위의 네 초기화를
seed2026/2027/2028 각각128회, 초기화당384회로 평가한다. 총6,144에피소드다.
정책은 deterministic, 동역학 DR 켬·관측 DR 끔, 같은 고정 reset bank를 사용한다.
성공은 낮은 합격 해제·안착·철수·A 복귀까지의 에피소드 마지막 전체 완료다.
첫 에피소드만 평가하며 물리/제어 실패는 별도로 기록하고 성공 분모에서 빼지 않는다.

## 기준과 결과

승급 후보 조건은 **네 초기화 각각 전체 완료192/384회 이상(50%)**이다.
전체 평균만50%인 경우는 통과하지 않는다. 접근/파지·들기/그릇 위 운반/합격 해제/안착의
중간 진척도도 별도로 남긴다. 이는 초기화별 전체 완료율과 다른 지표다.

비교 순위는 초기화별 최저 완료율 → 평균 완료율 → 동률일 때 적은 학습량 순이다.
비유한/접촉 용량 초과가 있는 결과는 후보에서 제외한다.
아무 체크포인트도 기준을 넘지 못하면 실패 지점을 비교하고 같은 쉬운 조건의 추가 학습·개선을 검토한다.
이 캠페인은 난이도를 자동 승급하거나 로봇/Thor 정책을 교체하지 않는다.

실행 디렉터리:

- `campaign.json`: 단계·프로세스·관측된 진행량·오류/완료 상태.
- `training/`: 네 원본 체크포인트, normalizer, 설정·reset bank·보상 계수·코드 revision·학습 통계.
- `evaluation/{2,4,6,8}u/`: 초기화별 평가 요약과 원시5ms 궤적.
- `comparison.json`, `comparison.csv`: 네 체크포인트의 동일 조건 비교.
- `videos/`: 비교 후보와 최종8배 모델의 첫 빈손A/held 사례1배속 영상. 성공 사례를 골라내지 않는다.

`--publish-dir`를 주면 최종 비교표와 영상을 지정 경로에도 복사한다.
장시간 실행은 조정 프로세스를 유지하여 학습·평가를 순서대로 실행한다.
중간 오류는 `campaign.json`과 단계별 log에 기록하고 중단한다.
