# 처음부터 위치 랜덤화를 포함하는 SHOW-103 학습

2026-10-30 사용자 지시에 따라 큐브·그릇 위치를 매 episode 랜덤화한 새 MLP를 처음부터 학습한다.
고정 위치 실행과 체크포인트·진단 영상을 보존한다. 학습량과 저장 시점은 이전과 동일하다.

| --- | --- | --- |
| 2 | 16,777,216 | `000016777216` |

4,096환경, seed7, 새 MLP256×256, actor49/critic66/action7과 초기화40/20/20/20%를 유지한다.
수식·그리퍼·DLS+QP·동역학DR·PPO 설정은 바꾸지 않는다. 관측 DR는 계속 끈다.

## 위치 표본

- 기준 XY 표본 범위: 큐브·그릇 모두 x=0.25~0.35m, y=−0.20~+0.20m, 반경≤0.40m.
- 빈손A는 팔을 A에 유지하고 큐브·그릇XY를 독립적인 연속 표본으로 뽑는다.
- 파지 직전/held는 실제 접촉을 검증한 팔–큐브 결합 자세64개에서 선택한다.
  팔·큐브를 joint1 축 기준으로 함께 최대±15° 회전해 연속적인 위치 변화를 더한다.
  그리퍼–큐브의 상대 방향·파지 깊이는 유지한다. 별도 상대 yaw·깊이 랜덤화는 추가하지 않는다.
  회전 후 세계 XY는 위 기준 범위보다 확장될 수 있으며 반경은 유지된다.
- 처음 세 초기화의 그릇은 다시 독립적인 연속XY를 뽑고 큐브와14cm 이상 이격한다.
- 그릇 위 시작은 검증된 held 자세와 그 바로 아래 그릇을 함께 이동한다.
  높이125mm와 관절 제한을 유지하므로 IK가 가능한 부분집합에서 선택한다.
  그 밖의 초기 높이는 파지 직전65mm, held100mm로 이전과 같다.
- CPU에서300ms 안정화한 실제 자세를 보관하며, reset 때 실제 world별DR로100ms 더 안정화한다.
  보상 메모리를 미리 채우지 않는다.

학습용/평가용 각각4초기화×64개 결합 자세를 독립 seed41030/51030으로 생성했다.
bank 파일은 `src/piper_sim_lab/assets/reset_banks/`에 NPZ·메타데이터·SHA-256으로 보관한다.
형상·TCP·물리 설정과 checksum이 다르면 로드를 거부한다.
평가기는 학습용과 다른 bank를 사용하며 연속 위치 표본도 평가 seed로 새로 뽑는다.

## 검증

[실제 GPU 물리 검사](random-position-validation.json): 학습 bank128/1,024/4,096환경,
평가 bank128환경에서 reset·24정책 스텝을 검사했다.
모든 경우 파지 reset 실패, 비유한, 용량 초과와 제어 오류가0이었다.
4,096환경 보드 GPU 최대 사용량은5,017MiB였다. 두 번째 reset에서도 메모리·접촉을 확인했다.
각 초기화의 실제 큐브/그릇 XY 표준편차가 두 축 모두1mm를 초과함을 확인했다.

기존 보상·환경·캠페인 검사36개, 위치 표본의 재현성/네 초기화 다양성/실접촉/독립bank/형상 거부 및
캠페인 검사11개를 통과했다(공통 캠페인 검사4개를 빼면 총43개).
[위치 검사 기록](random-position-tests.txt).

## 실행과 평가

```bash
export PYTHONPATH="$PWD/src:$PWD/runtime/src"
scripts/run.sh .venv/bin/python -u scripts/show103/run_stage_campaign.py \
  --config configs/show103/stage-reward-v1-4096-random-positions-2-4-6-8.yaml \
  --output runs/show103-random-positions-4096-s7-2-4-6-8u-20261030 \
  --artifact-prefix show103-random-positions
```

학습 종료 후 네 체크포인트를 평가 seed2026/2027/2028, 초기화별384회로 비교한다.
이전과 같은 전체 완료율50%(각192/384) 기준이며 중간 구간 진척도도 기록한다.
난이도는 자동 승급하지 않는다. `campaign.json`, 네 원본 checkpoint, bank·normalizer·resolved config,
원시 평가·비교표·첫 사례 영상은 새 실행 디렉터리에 남긴다.
`--publish-dir` 사용 시 새 결과는 `show103-random-positions-*` 이름으로 복사해 이전 결과와 구분한다.

## 이번 실험이 확인하는 것

위치 암기 여부는 가설이다. 고정 위치 영상에서 확인한 것은 그릇에서 이탈한 뒤에도
과거 도달 이력과 높이만으로 주보상3.5를 유지할 수 있는 경로다.
그 경로는 현재 수식에도 존재한다. 이번에는 요청대로 위치 랜덤화 효과를 분리하여 확인하며,
수식을 동시에 바꿔 효과를 섞지 않는다. 위치 랜덤화만으로 전체 완료가 개선되는지는 평가 결과로 판단한다.
