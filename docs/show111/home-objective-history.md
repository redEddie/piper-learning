# 관절 A에서 TCP 복귀로 변경한 실험 이력

2026-11-08 사용자는 관측 DR·확장 스폰 MLP+LSTM14+2배에서4배를 연장하도록 승인했다.
이번 연장은 기존 관절 A 보상 v5 계열이다. 아래는 후속 복귀 실험의 목표·보상·학습기 변경을 정리한 기록이다.

## 목표와 보상 변경

| 계열 | ⑤ 진행 보상 | 완료 조건과 추가 비용 | 결과 |
| --- | --- | --- | --- |
| v5 원본 | 각 관절 허용오차 초과량을 최대70%+평균30%로 합친 D를 진입 D0로 정규화한다. 접근0~0.8점과 유효 유지0~0.2점이다. | 모든 관절 오차≤0.2rad,최대 속도≤0.05rad/s,안착100ms,80mm 분리·비접촉,200ms 유지 | 관측 DR 없는 MLP16배에서⑤96.1%,① 시작 실제 A 전체75.3% |
| v5 관측 DR·확장 스폰 | 같은 관절 A 목표·보상 | 같은 관절 A 완료 조건 | 원본14배의 새 조건⑤0.3%에서 추가2배 후10.2%,① 시작 A 전체0→5.5% |
| 최대오차 전용 | D를 최대 허용초과 관절 오차100%로 바꿨다. 접근0.8+유지0.2다. | 기존 관절 A 완료 조건 | 시간 Transformer fresh2배에서⑤0/384 |
| 고정60° 기준 | 최대 절대 관절 오차가60°에서 접근0점,0.2rad에서0.5점이다. 유효200ms 유지로0~0.5점을 더한다. | 60° 초과분에60°당−0.5점,이후 관절 한계 때문에 삭감된 요청량에 계수0.5 비용 추가 | 누적8~16배⑤ 관절 A 완료 각0/384.16배 최종 최대 관절 오차 중앙21.82° |

| TCP60mm·선형 정지 | 위 접근 보상과 위치60mm·방향10°를 사용한다. 유효 정지 시간에 따라0→0.2점을 선형 지급한다. | TCP와 정지 조건으로 완료를 판정하고 기존 관절 A 완료도 별도 집계 | 시간 Transformer12배⑤ TCP83.9%,① 시작 전체 TCP0%.MLP14배⑤ TCP96.4%,① 시작 전체 TCP0%.기존 관절 A 완료는 두 실험 모두0회 |

v5의 D는 `0.7*max(e)+0.3*mean(e)`, `e_i=max(abs(q_i-A_i)-0.2,0)`이다.
허용오차 초과량이0인 관절의 오차 감소는 D에 영향을 주지 않는다. 최대오차 전용에는 최대가 아닌 관절의 변화가 보상에 반영되지 않는 구간이 생긴다.
v7 접근 보상은 오차 변화의 부호를 사용한다. 오차 감소량의 크기에 비례하는 보상은 적용하지 않았다.
⑤ 완료 이력 점수와 현재 허용범위·정지 보상을 구분하며,완료 후 이탈에는 별도 비용을 계산한다.

## 학습기 변경도 함께 기록

| 항목 | 관절 v5 MLP 기준 | 후속 TCP 실험 |
| --- | --- | --- |
| Actor | MLP256→64→LSTM128 | LSTM 없는 시간 Transformer,K/V64.이후 MLP+LSTM도 비교 |
| Critic | privileged66,MLP256×256 | privileged86,시간 Transformer 폭64·2층·4헤드·K/V64 |
| Critic 전용 입력 | 기존 실제 물리 상태 | 실제 단계·완료 이력·TCP 목표 오차·안착/정지 타이머·잔여 시간 추가 |
| PPO 구간 | 16스텝,1.6초 | 64스텝,6.4초 |
| 초기화·시간 | 4096환경,5개 각20%,200스텝 | 같은 환경 수·비율·에피소드 길이 |

보상·모델·critic·학습 구간·학습량이 함께 달라진 실험이다. 한 요소만의 효과를 입증하는 비교로 해석할 수 없다.
직접⑤를 초기화한 성공과①부터 이어 수행한 성공을 구분한다. 시간 Transformer12배에서는③ 초기화 후384회 모두④에 도달했지만 이후 OPEN 목표가 나온 사례는0회였다.
TCP 목표 부근에서도 최대 관절 A 오차 중앙값이 약100°인 사례를 확인했다. TCP 완료와 관절 A 완료는 서로 다른 지표다.

## 제어기 진단의 범위

자코비안·A 선호 QP와 TCP 목표 피드백을 구현하고 명목 물리32개 상태에서 A 정지32/32를 확인했다.
이 결과는 외부 A 목표를 주는 제어 진단이다. 경량화 후4096환경 처리량은7420전이/초였고 접촉 중 추종 한계 초과 리셋이 관측됐다.
이번 관측 DR MLP 연장은 부모와 같은 기존 DLS·QP 제어 계열로 실행한다.
